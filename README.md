# 柒扣科技官网

湖南柒扣文化科技有限公司官方网站静态页。独立于柒扣云证 App 原型，共用橙色品牌与思源黑体。

本地打开 `index.html`，或在本目录执行：

```bash
python3 -m http.server 5174
```

然后访问 http://127.0.0.1:5174

## 页面

| 文件 | 栏目 |
| --- | --- |
| `index.html` | 首页 |
| `copyright.html` | 著作权登记 |
| `app.html` | 柒扣云证 APP |
| `pc.html` | 柒扣云证 PC 端 |
| `solutions.html` | 解决方案 |
| `news.html` | 新闻动态 |
| `about.html` | 关于我们 |
| `download.html` | 下载 APP（商店链接待接入） |

文案来自《柒扣科技官网文案_全栏目纯文字稿》。配图位已留白，后续替换。

## 设计规范

- 主色 `#ff6f35`，按下 `#e85a24`
- 浅底 `#fff0e8` / `#fffaf6`
- 主文字 `#171717`，次级 `#88817c`
- 字体 Noto Sans SC（`assets/fonts/`）
- 图标为线框 SVG，取证类型沿用 App 辅助色
- 卡片使用轻阴影
