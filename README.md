# 柒扣科技官网

湖南柒扣文化科技有限公司官方网站。

本仓库独立于柒扣云证 App 原型（`Desktop/cursor`），但同属柒扣科技产品线。后续网站搭建详情确定后再补页面。

## 与柒扣云证的关系

- 官网介绍公司与产品，并可导向柒扣云证（App / 网页端存证）。
- 不复用 App 的手机画框、底部导航和 `8pt` 正文字号。
- 品牌色、字体、扁平视觉与 App 通用。

## 共用设计规范

来源：柒扣云证 `docs/ui-design-guidelines.md`、`assets/fonts.css`。

| 用途 | 值 |
| --- | --- |
| 主橙色 | `#ff6f35` |
| 深橙色（按下 / 强调） | `#e85a24` |
| 浅橙背景 | `#fff0e8` |
| 极浅橙背景 | `#fffaf6` |
| 主文字 | `#171717` |
| 次级文字 | `#88817c` |
| 正文字体 | Noto Sans SC（思源黑体）Regular |
| 标题字体 | Noto Sans SC（思源黑体）Black |

官网正文建议 `14px`～`16px`，保持扁平：少阴影、少玻璃拟态、少复杂渐变。
