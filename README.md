# 柒扣科技官网

湖南柒扣文化科技有限公司官方网站静态页。视觉沿用柒扣云证橙色规范：主色 `#ff6f35`，字体 Noto Sans SC。

本地打开 `index.html`，或在本目录执行：

```bash
python3 -m http.server 5174
```

然后访问 http://127.0.0.1:5174

## 页面

| 文件 | 栏目 |
| --- | --- |
| `index.html` | 首页 |
| `products.html` | 产品与服务总览 |
| `copyright.html` | 版权存证平台 |
| `app.html` | 柒扣云证 App |
| `pc.html` | 柒扣云证 PC 端 |
| `monitor.html` | 全网监测平台 |
| `blockchain.html` | 区块链存证 |
| `solutions.html` | 解决方案 |
| `cases.html` | 司法案例 |
| `download.html` | 下载与存证验证 |
| `about.html` | 关于我们 |
| `news.html` | 新闻动态（页脚入口） |

顶栏为：首页、产品服务、解决方案、司法案例、存证验证、关于我们。应用商店正式链接和证书在线核验接口仍待接入。

## 设计规范

- 主色 `#ff6f35`，按下 `#e85a24`
- 浅底 `#fff0e8` / `#fffaf6`
- 主文字 `#171717`，次级 `#88817c`
- 字体 Noto Sans SC（`assets/fonts/`）
- 正文 15px，主标题 42px，区块标题 32px
- 图标为线框 SVG，取证类型沿用 App 辅助色
- 卡片使用轻阴影
